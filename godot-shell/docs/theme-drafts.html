Each component is a function of the theme tokens and the rule parameters. The tables show what the current settings resolve to on this panel.

What feeds back into the shell

  • The chosen option becomes the default theme's theme.yaml: the color tokens for day and night, the type pairing, radius and density.
  • The rule parameters become the shell's rule table. The research fills it, and the scenario runner checks every page against it (touch targets, minimum text, list length while moving).
  • Each component here becomes one Godot scene with the same parameters, and one scenario with goldens across the theme matrix.
